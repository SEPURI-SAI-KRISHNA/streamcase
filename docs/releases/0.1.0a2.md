# Streamcase 0.1.0a2 release notes

**Status: candidate, not yet published.** Issue #128 prepares the reviewed
version, changelog, and notes. A separate release issue will tag, publish, and
verify this prerelease only after the required CI and release checklist pass.
Do not treat this document as evidence that a `v0.1.0a2` GitHub release or
PyPI distribution exists.

## Why this follow-up alpha exists

The published `0.1.0a1` wheel and sdist install successfully, but their PyPI
description contains pre-publication README text saying that no release exists
and users must install from a checkout. Published distribution metadata cannot
be edited in place. This candidate carries the corrected README-based long
description into a new version; `0.1.0a1` remains available and is not yanked.

The public runtime API, dependencies, and supported compatibility matrix are
unchanged from `0.1.0a1`. There are no new streaming features in this release.
The [first-alpha notes](0.1.0a1.md) describe the existing API and examples.

## Tested compatibility

| Component | Alpha support claim |
| --- | --- |
| Backend-independent package | Python 3.10, 3.11, 3.12, and 3.13; no Java or PySpark required |
| Spark runner | Python 3.11, Java 17, and PySpark 4.2.x together in local mode |

Core CI covers all four listed Python versions. The dedicated Spark lane tests
the full runner combination and clean wheel/sdist installs with the optional
`spark` extra. Passing core tests on another Python version does not establish
runner support there. See the [compatibility policy](../spark-compatibility.md).

## Known limitations and change expectations

- This is an **alpha** API. Later alphas may make breaking changes; do not
  assume stable compatibility or production support.
- The runner uses a JSON file stream, an explicit input schema, and local Spark
  testing. Spark 3.5, other Spark 4.x minors, other Java versions, and remote
  clusters are not in the tested support matrix.
- Progress, watermark, and state-store assertions; pytest fixtures or plugin
  registration; Kafka, Delta Lake, PyFlink, production monitoring, and
  checkpoint mutation are not included.
- The `spark` extra installs PySpark, but a compatible Java JDK must be
  installed separately.

## Installation after publication

Only after the separate release issue verifies publication on PyPI:

```shell
python -m pip install "streamcase==0.1.0a2"
python -m pip install "streamcase[spark]==0.1.0a2"
```

Until then, use an already-published version from
[PyPI](https://pypi.org/project/streamcase/) or follow the editable-install
instructions in the [contribution guide](../../CONTRIBUTING.md). The GitHub
release will provide the tag and notes; PyPI will provide the wheel and sdist.
Distribution files are not promised as GitHub release attachments.
