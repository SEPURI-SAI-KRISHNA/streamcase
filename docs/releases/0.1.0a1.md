# Streamcase 0.1.0a1 release notes

**Status: published prerelease on 2026-10-09.** The
[GitHub release](https://github.com/SEPURI-SAI-KRISHNA/streamcase/releases/tag/v0.1.0a1)
contains the tag and notes. The wheel and source distribution are available on
[PyPI](https://pypi.org/project/streamcase/0.1.0a1/). Issue #99 records the
release workflow, matching distribution hashes, and clean-install checks.

The published `0.1.0a1` PyPI description was built from an earlier README and
incorrectly says that no release exists and installation requires a checkout.
That wording does not affect package installation or the documented API; PyPI
does not update metadata inside an already-published distribution. A later
version is needed to publish the corrected description.

## What is included

- Immutable `Batch`, `Restart`, and `Scenario` inputs and immutable
  `CapturedBatch` and `ScenarioResult` outputs.
- Backend-independent row equality, batch-count, and unique-key assertions.
- A file-backed Spark Structured Streaming runner that writes JSON input
  batches, captures `foreachBatch` output, and resumes after a `Restart`
  action using the same checkpoint. The caller owns the Spark session;
  Streamcase owns the query and temporary run resources.
- An optional `spark` extra. The core package does not require PySpark or Java.

The [Spark runner guide](../spark-runner.md), [restart guide](../restart-scenarios.md),
and [results and assertions guide](../results-and-assertions.md) contain runnable
examples and API details.

## Tested compatibility

| Component | First-alpha support claim |
| --- | --- |
| Backend-independent package | Python 3.10, 3.11, 3.12, and 3.13; no Java or PySpark required |
| Spark runner | Python 3.11, Java 17, and PySpark 4.2.x together in local mode |

CI tests the core package on all four Python versions. The dedicated Spark
lane tests the complete runner combination and smoke-tests clean installs
from both the wheel and sdist with the optional `spark` extra. Passing core
tests on another Python version does not establish runner support there.
See the [compatibility policy](../spark-compatibility.md) for details.

## Known limitations and change expectations

- This is an **alpha** API. Later alphas may make breaking changes; do not
  assume stable compatibility or production support.
- The initial runner uses a JSON file stream, an explicit input schema, and
  local Spark testing. Spark 3.5, other Spark 4.x minors, other Java versions,
  and remote-cluster behavior are not in the tested support matrix.
- Progress, watermark, and state-store assertions; pytest fixtures and plugin
  registration; Kafka and Delta Lake sources; PyFlink; production monitoring;
  and checkpoint mutation are not included.
- The `spark` extra installs PySpark, but a compatible Java JDK must be
  installed separately.

## Install this historical version

To reproduce tests against `0.1.0a1`, install the exact prerelease version:

```shell
python -m pip install "streamcase==0.1.0a1"
python -m pip install "streamcase[spark]==0.1.0a1"
```

The `spark` extra does not install Java; provide a compatible Java 17 JDK
separately. GitHub release assets do not contain the wheel or source
distribution; those files are hosted on PyPI.
